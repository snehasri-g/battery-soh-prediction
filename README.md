# battery-soh-prediction
Lithium-ion Battery State-of-Health prediction using Hybrid LSTM-ANFIS model
## Dataset
This project uses the NASA Prognostics Center Battery Dataset (B0005).

Download from:
https://ti.arc.nasa.gov/tech/dash/groups/pcoe/prognostic-data-repository/

After downloading, place `B0005.mat` in the same folder as `soh_prediction.m` before running the code.
